# 东方花映塚 中文补丁内容频道

基础内容版本为 0.5.0，需要 LilyPatch 0.1.6 或更新版本。Steam 安装请使用 LilyPatch 0.1.8 或更新版本。
适用于 CD 版 1.50a 和 Steam 的 `ver150a` 测试分支，目标为同一份 x86 `th09.exe`。
游戏 EXE SHA-256 为 `10350095bcf95edb59e03bee9849a2dc8a7714b4927ad5909c569c550fce6822`。

若当前是 1.00a，CD 版请安装[官方 1.50a 升级补丁](https://kourindou.exblog.jp/1327589/)，
Steam 版请在游戏的「属性 → 游戏版本及测试版」中选择 `ver150a`。

- [对话、结局及其他内容](files/150a/)
- [音乐室曲名与说明](files/150a/data/sprt/musiccmt.txt.json)
- [窗口标题、菜单文字与诊断信息](files/150a/hardcoded.json)
- [符卡名称](files/150a/spells.json)
- [译图](files/150a/data/)

内容由 LilyPatch 在游戏运行时加载，原游戏 EXE 和 DAT 保持原样。

## 来源、署名与许可

对话、结局、音乐室、符卡、菜单等译文及译图来自 Touhou Patch Center 简体中文项目，署名为 thpatch lang_zh-hans contributors。
贡献者及修订历史见[简体中文项目](https://www.thpatch.net/wiki/Patch:Lang_zh-hans)、[TH09 页面](https://www.thpatch.net/wiki/Th09)
及[硬编码文字页面](https://www.thpatch.net/wiki/Hardcoded_strings/zh-hans)。
译文、译图及其派生内容按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 提供，见 [Touhou Patch Center 许可说明](https://www.thpatch.net/wiki/Touhou_Patch_Center:Servers)。

LilyPatch 将译文整理为 JSON，将译图合成为完整图像并转换为游戏所需格式。窗口标题及部分诊断和联机状态中文由 LilyPatch 翻译，同样采用 CC BY-SA 4.0。
